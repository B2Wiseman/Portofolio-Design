# LOOP — Creative Portfolio

A static GitHub Pages-ready portfolio rebuilt from the visual language and interaction patterns observed on Studio Loop's public homepage. It is intentionally implemented from scratch with editable HTML/CSS/JS rather than copying the site's compiled application code.

## Media placeholders
- `assets/images/image-01.jpg` through `image-12.jpg` = 12 image slots.
- `assets/videos/video-01.mp4` through `video-06.mp4` = 6 vertical video slots.
- Video holders are designed for **1080 × 1920 px (9:16)** source videos.

Replace the files while keeping the filenames to update the portfolio without editing HTML.

## GitHub Pages
Upload the folder contents to a repository and enable GitHub Pages from the repository's Pages settings. No build step is required.

## Notes
The layout uses a warm off-white background, oversized editorial typography, vertical work labels, hover-reveal media, pinned horizontal desktop gallery, mobile stacked gallery, scroll motion, marquee, custom cursor, and 9:16 video feature.
